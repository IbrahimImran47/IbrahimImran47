## What I'm Building

**[ChipGhost](https://github.com/IbrahimImran47/chipghost)** — an open-source FPGA-based chip-in-the-loop test platform.
Pull a chip. Plug us in. We pretend to be it — and tell you what's wrong.
Combines a logic analyzer, pattern generator, and reactive engine into one $69 device.
Built on a Lattice ECP5 with a fully open-source toolchain (Yosys + nextpnr).

**[NetNerd](https://github.com/IbrahimImran47/netnerd)** — an AI agent that SSHs into
multi-vendor network devices and handles topology mapping and config through natural language.
